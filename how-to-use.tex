\subsection*{First-Time Setup}
\begin{enumerate}[leftmargin=1.5em, itemsep=0.5pt, topsep=1pt]
    \item \textbf{Extract the ZIP}: Right-click the downloaded zip file $\rightarrow$ \textbf{Extract All...}
    \item Open \textbf{3D Slicer}.
    \item In the menu, go to \textbf{Edit} $\rightarrow$ \textbf{Application Settings} $\rightarrow$ \textbf{Modules}.
    \item Under \textbf{Additional module paths}, click \textbf{Add} and select the \textbf{\texttt{BoundingBoxNavigator}} folder.
    \textit{Tip:} if the settings window is small, the \textbf{Add} button is hidden behind a \textbf{\texttt{>{}>}} button to the right of the \textbf{Additional module paths} box; click \textbf{\texttt{>{}>}} to reveal it.
    \item Click \textbf{OK} and restart Slicer.
\end{enumerate}
{\footnotesize\noindent\textbf{macOS:} Drag Slicer from the disk image into \textbf{Applications} (do not run it from the disk image). The first time, right-click Slicer $\rightarrow$ \textbf{Open} $\rightarrow$ \textbf{Open}. Move this tool's folder to your home folder (Finder: Cmd+Shift+H), not Downloads, Desktop, or Documents, or the module disappears after a restart. Then double-click \texttt{launch\_mac.command}.\par}

\subsection*{How to Annotate}
\begin{enumerate}[leftmargin=1.5em, itemsep=1.5pt, topsep=1pt]
    \item \textbf{Open the Module}
    \begin{itemize}[leftmargin=1.2em, itemsep=0.5pt]
        \item In the top toolbar, go to: \textbf{Modules} $\rightarrow$ \textbf{Annotation} $\rightarrow$ \textbf{Bounding Box Navigator} to display the panel on the right.
    \end{itemize}

    \item \textbf{Select Folders \& Scan}
    \begin{itemize}[leftmargin=1.2em, itemsep=0.5pt]
        \item Set \textbf{Input Scans Folder} (where your CT scans are) and \textbf{Output Annotations Folder}.
        \item Click \textbf{Scan Folder}. The first unreviewed case loads automatically.
        \item Each slice view shows the \textbf{original} scan for that plane when the file exists; otherwise it reconstructs from the axial volume (a warning is shown).
    \end{itemize}

    \item \textbf{Draw Bounding Boxes}
    \begin{itemize}[leftmargin=1.2em, itemsep=0.5pt]
        \item Choose a \textbf{Finding type} (default: PM nodule). Then press \textbf{\fbox{\textbf{B}}} (or click \textbf{+ Add Bounding Box}).
        \item \textbf{Click and drag} across the lesion on any slice view (axial, coronal, or sagittal).
        \item Drag the colored handles on the box to resize it in width, height, and depth.
        \item Scroll through slices with your mouse wheel to check coverage.
        \item Use the large \textbf{slice thickness} buttons (3\,mm, TS, \ldots). For TS (or any thickness without native COR/SAG), coronal and sagittal show reconstructions of that axial scan.
        \item Press \textbf{\fbox{\textbf{B}}} again for each additional lesion.
        \item \textit{To hide or show a box}: untick / tick the \textbf{Show} checkbox in front of it in the box list. Hidden boxes are still saved; this only hides them while you look at the scan.
        \item \textit{To remove a box}: click it in the list and press \textbf{Delete Selected}.
    \end{itemize}

    \item \textbf{Notes / PCI Score}
    \begin{itemize}[leftmargin=1.2em, itemsep=0.5pt]
        \item Type the PCI score or clinical comments in the \textbf{Notes / PCI} field (optional).
        \item Optional: in \textbf{4.\ Segmentation}, load a \texttt{.seg.nrrd} or \texttt{.nii.gz} overlay (\texttt{.nii.gz} is imported as a labelmap, not a CT volume).
    \end{itemize}

    \item \textbf{Save and Next Scan}
    \begin{itemize}[leftmargin=1.2em, itemsep=0.5pt]
        \item Click \textbf{Save + Next} (large green button).
        \item Each box is saved as \texttt{R\_1.mrk.json}, \texttt{A\_1.mrk.json}, \ldots inside a folder named after the case ID.
        \item The next unreviewed scan loads immediately.
        \item \textit{If there are 0 lesions (PCI 0)}: click \textbf{Save + Next} and confirm with \textbf{Yes}.
    \end{itemize}
\end{enumerate}

{\Large\bfseries\color{darkblue} Troubleshooting: folder layout} \hfill {\small\bfseries Quick User Guide}\\[-0.2cm]
\rule{\textwidth}{0.8pt}

\vspace{0.15cm}
The case name comes from the \textbf{filename}, not from the folder the file sits in. Subfolders are searched. Two patterns are accepted, and both may sit in the same folder:

\begin{center}
\small
\texttt{\{case\_id\}\_\{AX|COR|SAG\}\_\{phase\}\_\{thickness\}.nii.gz}\\[0.15em]
\texttt{\{case\_id\}\_\{scan number\}\_\{AX|COR|SAG\}\_\{phase\}\_\{thickness\}.nii.gz}
\end{center}

\vspace{-0.15cm}
\begin{itemize}[leftmargin=1.3em, itemsep=1pt, topsep=2pt]
    \item \textbf{case\_id}: one token, no underscores (example: \texttt{1001}).
    \item \textbf{scan number}: optional digits (\texttt{2} or \texttt{02}). When it is absent, the scan is number 1, so \texttt{1001\_AX\_\ldots} and \texttt{1001\_1\_AX\_\ldots} are one case, \texttt{1001}. Scan 2 and higher are their own case, such as \texttt{1001\_2}.
    \item \textbf{Plane} must be \texttt{AX}, \texttt{COR}, or \texttt{SAG}. Every case needs an \texttt{AX} file. A missing \texttt{COR} or \texttt{SAG} is reconstructed from the axial scan, and a warning is shown.
    \item \textbf{Phase} (for example \texttt{pvp}) is read and then ignored for grouping. \textbf{Thickness} is \texttt{3mm}, \texttt{TS}, \texttt{2mm}, and so on.
\end{itemize}

\subsection*{Layouts that work}
{\footnotesize
\begin{verbatim}
scans/                                      annotations/   (created on Save)
  1001_AX_pvp_3mm.nii.gz                      1001/
  1001_COR_pvp_3mm.nii.gz                       R_1.mrk.json
  1001_SAG_pvp_3mm.nii.gz                       _annotation_done.json
  1001_2_AX_pvp_3mm.nii.gz                    1001_2/
  1001_2_COR_pvp_3mm.nii.gz                     R_1.mrk.json
  patient_1004/                                 _annotation_done.json
    1004_AX_pvp_3mm.nii.gz
\end{verbatim}
}
\vspace{-0.35cm}
{\small
\texttt{1001\_*} is case \texttt{1001}, scan 1. \texttt{1001\_2\_*} is case \texttt{1001\_2}. \texttt{patient\_1004/} does not matter: \texttt{1004\_AX\_\ldots} is case \texttt{1004}.
On Save, boxes go to a folder of that same name. An existing folder is reused when it is named exactly \texttt{1001} or \texttt{1001\_2}, or when the name contains that id (\texttt{Scan 1001}). The folder \texttt{1001\_2} is not used for case \texttt{1001}.
\par}

\subsection*{When the scan does not line up}
\begin{center}
\small
\renewcommand{\arraystretch}{1.12}
\begin{tabular}{@{}p{0.40\textwidth}p{0.56\textwidth}@{}}
\toprule
\textbf{What you see} & \textbf{How to align the files} \\
\midrule
Two scans of one patient become one case, or boxes are saved in the wrong folder &
Put the scan number in the filename: \texttt{1001\_2\_AX\_pvp\_3mm.nii.gz}. A folder named \texttt{1001\_2} is not enough. \\
A warning names a contrast phase conflict, or a file is ignored as a duplicate &
Keep one scan per case id and scan number. Give another scan its own number, such as \texttt{1001\_2\_AX\_art\_3mm.nii.gz}. \\
The case is called \texttt{image} or \texttt{volume}, not \texttt{1001} &
The id is only on the folder. Rename the file so the id is in the name. \texttt{scans/1001/image.nii.gz} is case \texttt{image}. \\
A case never appears &
Add an axial file (\texttt{AX}). Coronal and sagittal files alone are not a case. \\
Coronal and sagittal are reconstructions, and the case name is the whole filename &
The name does not match the pattern above. Keep the order: case id, optional scan number, plane, phase, thickness. \\
\textbf{Scan Folder} finds nothing &
Point \textbf{Input Scans Folder} at the folder of \texttt{.nii.gz}, \texttt{.nii}, \texttt{.nrrd}, \texttt{.nhdr}, \texttt{.mha}, or \texttt{.mhd} files, not at the annotations folder. \\
\bottomrule
\end{tabular}
\end{center}

\vspace{0.15cm}
{\footnotesize\color{gray} A file that matches neither pattern is still loaded as its own case. A markup file that cannot be read is kept and listed. Unsaved changes ask before leaving. A geometry pop-up lists orientation, spacing, origin, or a box outside a reconstructed view.}
